# Todo App

Небольшое учебное React-приложение для управления списком задач.

## Возможности

- Добавление, редактирование и удаление задач; пустой текст не принимается.
- Отметка выполненных задач.
- Фильтры All / Active / Completed.
- Счётчик оставшихся задач и удаление выполненных.
- Отображение времени создания задачи через date-fns.

## Стек и реализация

React, JavaScript, CSS, date-fns, PropTypes, Create React App.

В текущей default branch главные компоненты App и NewTaskForm — классовые. Компоненты отображения используют функции. Данные задач хранятся в состоянии App.

## Локальный запуск

```bash
npm ci
npm run start
```

`npm run build` — сборка, `npm run lint` — проверка кода.


## Ограничения

- Задачи не сохраняются после перезагрузки страницы.
- Название репозитория `todos-on-hooks` не соответствует реализации основной логики.
- Публичное демо из About содержит поля времени, которых нет в коде default branch. До согласования версий ссылка на демо не включена в это описание.

`CI=true npm test -- --watchAll=false --runInBand` проверяет добавление, редактирование, отмену и сохранение свойств задачи.
